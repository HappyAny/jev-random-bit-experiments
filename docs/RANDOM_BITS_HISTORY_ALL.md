# Jev 0/1：保留全部历史作为 state

**从同一初始历史 `01010` 出发，保留全部历史测试 200 次，新输出仍全部为 0。** 所有请求成功；200 条反馈链逐条核验通过，初始五位不计入输出统计。

## 请求方式

沿用上一轮的 `jev-1.13.0`、问题和 `0` 在前、`1` 在后的选项顺序。首个请求与上一轮滚动五位试验完全相同，此后每次追加实际返回值，不再删除最旧一位。这里的“全部历史”指本轮初始五位及本轮之前的所有输出，没有拼接其他试验组的数据。

```json
{"previous_bits_oldest_to_newest": [0, 1, 0, 1, 0]}
```

| 请求 | 发送的历史 | 长度 |
|---|---|---:|
| 第 1 次 | `01010` | 5 |
| 第 2 次 | `01010` + 第 1 次输出 `0` | 6 |
| 第 200 次 | `01010` + 前 199 个输出 `0` | 204 |
| 完成后保存 | `01010` + 全部 200 个输出 `0` | 205 |

模型输入中没有时间戳或盐。采集于 2026-09-22 12:07:01–12:08:22（Asia/Shanghai），共 200 次 HTTP 200；串行执行，每次一个 Choice，没有自动重试、本地输出抽样或按结果提前停止。

## 结果与对照

| 条件 | 新输出数 | 0 | 1 | 返回 P(0) 均值 |
|---|---:|---:|---:|---:|
| 上一轮：只留最近五位 | 200 | 200（100%） | 0（0%） | 0.59815 |
| 本轮：保留全部历史 | 200 | 200（100%） | 0（0%） | 0.66360 |

本轮 P(0) 范围 0.55–0.74，所有响应都把 0 列为更高概率的选项。按每 50 次分组，P(0) 均值依次为 0.6390、0.6718、0.6762、0.6674，并非随历史长度单调上升。这些是响应中的概率值；实际返回的 choice 仍全部为 0。

上一轮历史最终重复为 `00000`，本轮因长度不断增加，200 个输入 state 全部不同，初始的两个 1 也一直保留。完整历史在这条轨迹上没有改善输出比例。两组采集时间不同，没有随机交错，不能仅凭均值差异确定因果，也不能推断所有初始历史都会如此。

[官方 Choice 定义](https://docs.typesafe.ai/primitives/choice)选择最大概率的选项，本轮输出符合该规则；改变 state 并不等于让 API 按返回概率抽样。这里没有核实模型内部的随机机制。

200 个新输出的最长连续 0 为 200，只有一个游程。在公平独立比特假设下，精确双侧频数检验 p≈1.2446×10⁻⁶⁰，明显不符合该假设。常量序列的 Pearson 相关系数未定义，游程正态近似不适用。即使其他试验出现 50/50，也不能仅凭比例证明随机性。

## 验证与保存

运行前检查了语法、默认固定输入未变、两种历史模式首个请求一致及互斥参数。运行后核对全部 200 条实际请求、完整历史的追加关系、CSV 与原始 choice 一致、模型与选项顺序、概率、token 合计、时间记录以及序列 SHA-256。请求中的历史逐次恰为初始五位加全部已返回值，未截断。统计程序沿用此前通过 4 项单元测试的版本。

本组输入 105,000 token、输出 6,200 token，请求端到端耗时中位数 399.285 ms。各试验组的原始数据独立保留；仅归档本文无凭据 Markdown 快照，draft / mixed，有限样本不能作为随机性认证。
