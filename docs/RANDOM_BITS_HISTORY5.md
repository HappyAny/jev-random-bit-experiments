# Jev 0/1：滚动使用前五次输出作为 state

**新生成的 200 个值全部为 0。初始历史为 01010；第 5 次请求起，历史固定为 00000，之后 196 次都返回 0。**

## 本次对“历史数据”的解释

使用最近五个 0/1，按从旧到新的顺序组成 state。首轮由本地 `secrets.randbits(1)` 连续五次初始化，实际得到 `[0, 1, 0, 1, 0]`；这五个起始值不计入 200 个测试输出。此后不再生成本地随机值，只将实际 Jev choice 加入末尾、删除最旧的一位。

本次没有把前一组“仅盐”试验的末五个值拿来初始化，也没有在每次请求中重新抽五个本地随机值。模型与问题沿用前几轮，去掉时间戳和盐。

首个实际请求的 state 为：

```json
{"previous_bits_oldest_to_newest": [0, 1, 0, 1, 0]}
```

采集时间为 2026-09-22 11:02:26–11:04:05（Asia/Shanghai）。全部 200 次 HTTP 200，实际模型均为 `jev-1.13.0`；每次一个 Choice，固定运行 200 次，没有自动重试、按结果提前停止或本地输出抽样。

## 实际反馈过程

| 请求范围 | 输入的五位历史 | 返回 0 | 返回 1 |
|---|---|---:|---:|
| 第 1 次 | 01010 | 1 | 0 |
| 第 2 次 | 10100 | 1 | 0 |
| 第 3 次 | 01000 | 1 | 0 |
| 第 4 次 | 10000 | 1 | 0 |
| 第 5–200 次 | 00000 | 196 | 0 |
| 合计 | 访问了 5 种历史状态 | 200（100%） | 0（0%） |

```text
01010 --输出0--> 10100 --输出0--> 01000
      --输出0--> 10000 --输出0--> 00000
      --输出0--> 00000 --输出0--> ...
```

上面的变化已逐条核对实际请求，而不是根据预期逻辑推测。200 次窗口更新全部正确，末尾历史为 `[0,0,0,0,0]`。

## 概率与解释边界

- 本组 P(0) 范围 0.56–0.65，均值 0.59815，所有返回都更倾向于 0。
- [官方 Choice 定义](https://docs.typesafe.ai/primitives/choice)选择最大概率的选项；本轮观察符合这一规则。前五次历史反馈很快变成相同输入，没有出现 1 将窗口改变。
- 对 200 个新输出做精确双侧频数检验，在公平独立比特零假设下 p≈1.2446×10⁻⁶⁰；最长连续 0 为 200，输出明显不符合公平独立比特。常量序列没有方差，Pearson 相关系数未定义；游程正态近似不适用。
- 这是一个随机初始窗口的一条轨迹，只访问了 32 种可能五位历史中的 5 种。没有覆盖全部初始历史，也没有证明未来永远不会离开 00000；“持续输出 0 的循环”只描述本轮实际观察。
- 若其他历史产生近似 50/50 的输出，仍需排查固定交替或短周期，单凭比例不能证明随机性。
