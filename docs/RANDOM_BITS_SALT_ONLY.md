# Jev 0/1：只保留随机盐，移除时间戳

**200 次得到 199 个 0（99.5%）和 1 个 1（0.5%）。唯一的 1 出现在第 168 次。**

| 条件 | 次数 | 0 / 1 次数 | 平均 P(0) | P(0) 范围 |
|---|---:|---:|---:|---:|
| 固定输入 | 1,000 | 1,000 / 0 | 0.68805 | 0.63–0.75 |
| 仅时间戳 | 200 | 200 / 0 | 0.64365 | 0.60–0.69 |
| 时间戳 + 随机盐 | 200 | 200 / 0 | 0.54810 | 0.51–0.60 |
| 本次：仅随机盐 | 200 | 199 / 1 | 0.58280 | 0.49–0.67 |

本次采集时间为 2026-09-22 10:52:37–10:54:31（Asia/Shanghai），200 次全部 HTTP 200，实际返回模型均为 `jev-1.13.0`。每次一个 Choice，顺序调用；样本量在运行前固定为 200，没有自动重试、输出替换或按结果提前停止。

## 实际输入

保留同一模型、英文随机比特提示与 0、1 选项顺序，只改变 state 中的随机盐。每次通过 `secrets.token_hex(16)` 重新生成 16 字节随机值，并编码为 32 个十六进制字符。

```text
No other information is provided.
Random salt: <每次重新生成的 32 位十六进制盐>
```

已核验 200 个盐及 state 各不相同，**每条实际提交的 JSON 正文都不含时间戳**。CSV 与日志仍有本地记录时间，方便追溯，但它没有发送给模型。每次模型输入保存在 raw.jsonl 的 `request` 字段。

## 唯一返回 1 的记录

第 168 次实际答案：

```json
{
  "type": "choice",
  "choice": "1",
  "confidence": 0.02,
  "probabilities": {"0": 0.49, "1": 0.51}
}
```

可直接检查 [raw.jsonl 第 168 行](../data/salt-200/raw.jsonl#L168)。另一条第 101 次在返回精度上为 0.50 / 0.50，choice 为 0；不能仅凭这一条推断服务内部的所有平局处理规则。

[官方 Choice 定义](https://docs.typesafe.ai/primitives/choice)是选择概率最大的选项。唯一返回 1 的这一条，P(1) 正好高于 P(0)，所以观察仍符合该规则，不能当作按 probabilities 随机抽样的证据。

## 本地统计与解释边界

- 频数为 199:1，明显不符合公平独立随机比特；精确双侧二项检验 p≈2.50165×10⁻⁵⁸。
- 最长同值连续段为 167；整条序列是 167 个 0、1 个 1、32 个 0。相邻转移为 00:197、01:1、10:1、11:0。
- 相邻 Pearson 相关系数约 -0.00505。接近 0 不足以证明随机性，尤其这里的频数极端不均衡；游程正态近似因 1 的数量过少不适用。
- 各组在不同时间段采集，未随机交错，其差异只作描述。这一条 1 不证明去除时间戳能稳定改善均衡性，也不能证明模型内部真随机；本地生成的盐本身就是外部随机输入。
